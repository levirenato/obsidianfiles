Meu trabalho vai ser sobre MCP server para servir de correção automática de trabalhos de alunos.

- qual a ideia?
  estudando ti na faculdade pude notar uma falta de automação no processo de correção de atividades praticas. tendo isso em vista pensei em desenvolver uma aplicação juntamente com i.a usando um [mcp server].
- como ele iria funcionar?
  Seria um servidor mcp capaz de ser integrado com api externas como claude ai, gpt, ou o proprio ollama, para que ele analise o codigo utilizando ferramentas especificas de analise, não somente utilizando a propria llm, dessa forma a gente economiza processamento.

- integrações o mcp server:
	1 - [sonarqube]
	2 - [ferramentas de benchmark] -> a pesquisar
	3 - [hash de release] -> para evitar plagio ou checar similiaridade com i.a
	4 - [integrar com google api]
