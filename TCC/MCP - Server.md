### O que é?
- O [mcp server] é um padrão de código aberto para conectar aplicativos de IA a sistemas externos. Pense no MCP como uma porta USB-C para aplicativos de IA, ele vai fornecer uma maneira de padronizada de conectar aplicativos de IA a sistemas externos.
